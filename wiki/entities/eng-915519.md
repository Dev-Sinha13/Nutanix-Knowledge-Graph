## Description
Kronos ticket that adds `authoringScope` to global ACPs and Roles: a read-only scalar `{NC, PC}` stamped by the server at create time. Implementation spans three repos with open PRs `ntnx-api-iam#910`, `iam-utils#357`, and `iam-themis#1601`. Hard blocker is a go-swagger pin owned by Manish; existing-row backfill is still open.
