# Review comment certainty

## Failure mode
Acting on bot suggestions or design pushback as if they were mechanical nits.

## Workaround

| Category | Action |
| --- | --- |
| Mechanical | Do it |
| Explicit human doc/comment request | Minimal match |
| Behavior change, local, you understand why | Do it |
| Bot AI | Ignore unless a human asked |
| Design “should we do X instead?” | Design-lead input |
