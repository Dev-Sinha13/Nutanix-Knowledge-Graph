# ENG-948242 — Backend-driven entity search metadata

Back: [IMPACT index](README.md) · Hub: [Nutanix Technical stack](../inbox/Nutanix%20Technical%20stack.md)  
Canonical log (in-repo, not this vault): `iam-themis/.notes/ENTITY_SEARCH_METADATA_CONTEXT.md`

---

## 1. The problem

IAM Entities store a rich attribute document (`object_attribute_list` JSONB). Nutanix Central search needs **named metadata on those attributes** (six optional strings), with three shapes:

- **direct** attributes
- **delegated** attributes
- **legacy** attributes that must **omit** metadata

Without a backend contract, NC cannot query entities by the fields operators type. v1, `/proxy`, v4 seed, and GET/LIST would drift. Nested internal vs public JSON names (`displayName`/`uiDisplayName` vs `name`/`displayName`) make naive unmarshal **silently put values in the wrong fields**.

This is findability, complementary to `products` (topology) and `authoringScope` (provenance).

---

## 2. How it was solved

- Six optional per-attribute search metadata strings in `objects.json`.
- Persist in the **existing** JSONB document (no new table).
- Expose on **v4 Entity GET and LIST**.
- Explicit conversion between internal and public nested names.
- **Kronos b4 swagger** copied byte-for-byte from ntnx-api-iam generated artifact into Themis `swagger-iam-v4.1.b4-all.yaml`; released b3 left unchanged. SHA-256 + middleware tests.
- Tavern: every write path (v1, proxy, v4 seed) × direct/delegated/legacy × all six fields × LIST and GET-by-ID (14 stages after `c4e1d16f5`).

PRs in notes: API #936, Utils #381, Bootstrap #787, Themis #1630.

## 6. Significant technical difficulties

**Silent field swap on nested models.** Internal `displayName`/`uiDisplayName` vs public `name`/`displayName`. Approach: **explicit converters**; never direct JSON unmarshal across that boundary.

**b3 fixtures vs b4 runtime.** Feature tavern green + fleet red looks like “you broke IAM.” Approach: inspect **which service image, test image, and swagger** deployment selected; publish a matched pair; do not weaken passing metadata assertions.

**Schema-changing overlay.** Runtime without matching `/v4/schema_yamls` is a different product. Approach: overlay yaml **and** binary; copy generated swagger byte-for-byte.

**`go get` of newer ntnx-api-iam broke Themis** (`AssociatedEndpoint.ApiVersion` became `*string`). Approach: reuse nil-safe handling from iam-themis PR #1619, do not invent a second representation.

**ntnx-api-iam codegen on JDK 21.** Generator requires `--add-opens`; missing flags fail on `java.lang.Enum.name`. Approach: reuse the exact recorded Maven command.

**Do not empty-commit through deterministic CI.** Approach: change the cause (images/base); rerun only for transient infra.

**Credential in verbose deploy logs.** Approach: rotate, redact, never copy into vault or PR text.

Proxy-write vs v4-seed **deployed** paths remain separate gates in the notes. Re-check GitHub for merge.
