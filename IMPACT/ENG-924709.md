# ENG-924709 — Configurable global-role deletion guardrail

**Company impact:** A **runtime, in-memory** flag can block deletion of global roles (configurable guardrail). The company-visible risk is not the flag itself — it is **confusing it with durable, cross-pod migration completion** (ENG-953364). Shipping the wrong “done” signal is how an upgrade looks finished on one pod and unguarded on the next.

## What it is

A configurable **global-role deletion guardrail**. Implementation uses an **in-memory runtime flag**.

That is appropriate for:

- Fast, process-local behavior (this pod, this process).
- Operator/feature-flag style switches that may reset on restart.

That is **not** appropriate for:

- “Has every tenant been migrated?” (must survive restart, must be shared across replicas).
- Cross-pod agreement about brownfield `products` completion.

---

## Why calling this out is the deliverable

Kronos had several “are we done?” bits in the same months:

| Signal | Durable? | Cross-pod? | Ticket |
| --- | --- | --- | --- |
| Role-products migration completion | Yes (coordinator) | Yes | ENG-953364 |
| ETag conflict during that migration | Error path + retry | Coordinator retries | ENG-956163 |
| Global-role delete guard | **No — in-memory** | **No** | **ENG-924709** |

If an engineer (or agent) copies the 924709 flag pattern into 953364, **a restart or a second replica silently re-allows work that the first pod thought was finished** — or worse, marks completion from local memory.

The impact of this ticket on the company is therefore twofold:

1. **Product:** a safety switch for deleting global roles (NC-authored, lattice-replicated objects you do not want a local admin to remove casually).
2. **Program integrity:** an explicit warning in the shared IAM notebook so the next migration does not reuse the wrong persistence model.

---

## How to use this note

When planning any “guardrail” or “completion” for Global IAM:

- If the question is “may this API call proceed on **this process**?” — a runtime flag can be enough (this ticket’s pattern).
- If the question is “has the **fleet** finished a migration?” — persist in the coordinator, fan out tenants, do not use 924709’s in-memory flag.
