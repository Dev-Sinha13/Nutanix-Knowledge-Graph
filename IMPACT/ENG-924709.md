# ENG-924709 — Configurable global-role deletion guardrail

Back: [IMPACT index](README.md) · Hub: [Nutanix Technical stack](../inbox/Nutanix%20Technical%20stack.md)

---

## 1. The problem

Global roles are lattice-replicated. Accidental **DELETE** from the wrong plane is a high-severity IAM incident. The product needed a **configurable guardrail** on global-role deletion.

A second, quieter problem: Kronos was simultaneously inventing **durable migration completion** (ENG-953364). An in-memory process flag and a fleet-wide “done” bit look similar in code review and are **not interchangeable**. Using the 924709 pattern for 953364 would mean a restart or a second replica **forgets** the guard or **falsely completes** a migration.

---

## 2. How it was solved

A **runtime, in-memory** flag that can block deletion of global roles (configurable). Appropriate for “may **this process** allow this API call?” Not appropriate for “has **every tenant on the fleet** finished a migration?”

---

## 3. Impact

- **Product:** a safety switch against deleting global roles from a context that should not.
- **Program:** an explicit warning in the shared IAM notebook so completion/guardrail work in the same months does not reuse the wrong persistence model.

---

## 4. How it was done

Implemented as an in-memory runtime flag in Themis (not a Bootstrap completion record). Documented alongside 953364/956163 as a **feature-specific decision that is not universal**.

---

## 5. Technologies and skills

- Go service runtime configuration / feature-style flags.
- Distinguishing **process-local** vs **durable cross-pod** state — a distributed-systems skill, not a new language.

---

## 6. Significant technical difficulties

**The difficulty is architectural, not a debugger session.** Three “are we done / may we proceed?” bits landed close together:

| Signal | Durable? | Cross-pod? | Ticket |
| --- | --- | --- | --- |
| Products migration completion | Yes | Yes | 953364 |
| ETag conflict during that migration | Error + coordinator retry | Yes | 956163 |
| Global-role delete guard | **No** | **No** | **924709** |

Approach: name the persistence model in the cross-issue notebook; when planning the next guardrail, ask which question is being answered before copying a flag.
