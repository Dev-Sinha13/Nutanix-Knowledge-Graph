# Inbox

Source notes for **Karpathy LLM Wiki**. Put new work here; do not put generated wiki pages here.

The plugin is set to **watch this folder** and notify when a note changes. After an LLM is configured:

1. Command palette → `Karpathy LLM Wiki: Ingest from folder`
2. Choose this `inbox` folder
3. Start with the ticket `00 - Index` notes plus [[Nutanix Technical stack]]

Skip this README when ingesting if the picker lets you exclude files.
